[2026-07-09] python-pptx PPT生成铁律（本次会话惨痛教训）
1. 白色颜色变量必须命名为 `WHITE`，不要用 `W`——会和 `W=13.333`（slide_width）冲突导致 `ValueError: assigned value must be type RGBColor`

4. 中文引号 `""` 在 Python 字符串中会触发 SyntaxError，全局改用 `「」`
5. `Pt(0)` 不合法，最小字号 `Pt(2)`
6. `t()` 函数调用时，在 align 参数前必须补 `False`（bold 占位），否则 `PP_ALIGN.CENTER` 会被映射到 bold→TypeError
